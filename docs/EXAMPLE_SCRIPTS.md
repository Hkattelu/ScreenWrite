## Example 1: Software Tutorial

**Filename:** `python-quickstart.md`

```markdown
# Python Quick Start Guide

## Introduction

Welcome to Python programming for absolute beginners. In this tutorial, we'll install Python, write our first program, and learn basic programming concepts that will set you up for success.

## Installing Python

Visit the official Python website at python.org and click the download button. The installer will automatically detect your operating system and recommend the correct version for your computer.

Run the downloaded installer and make sure to check the box that says add Python to PATH. This step is crucial because it allows you to run Python from any command prompt or terminal window.

## Setting Up Your Code Editor

Download Visual Studio Code from the official Microsoft website. It's a free, powerful editor that works great for Python development and has excellent extensions for coding.

Open Visual Studio Code and click on the Extensions icon in the left sidebar. Search for the Python extension by Microsoft and click the install button to add Python support.

## Writing Your First Program

Create a new file in Visual Studio Code and save it as hello.py on your desktop. Type the print function with the message "Hello World" inside quotation marks and parentheses.

Click the green run button in the top right corner of the editor. You should see your message appear in the terminal panel at the bottom of the screen.

## Understanding Variables

Variables are containers that store data values in your program. In Python, you create a variable by choosing a name and using the equals sign to assign it a value.

Type a variable called message and set it equal to your favorite quote. Then use the print function to display your variable on the screen just like before.

## Working with Numbers

Python can perform mathematical operations like addition, subtraction, multiplication, and division. Try creating two variables with numbers and adding them together using the plus sign.

Print the result of your calculation to see the answer. Python automatically handles the math for you and displays the correct result in the terminal window.

## Next Steps

Congratulations on writing your first Python programs and learning about variables and basic math operations. Continue practicing these concepts by creating your own simple programs and experimenting with different values.
```

**Expected Output:**
- ~10 beats
- Durations: 5-10 seconds each
- Strong visual keywords: "Python", "download button", "Visual Studio Code", "Extensions icon", "green run button"
- Clear action verbs: "visit", "click", "type", "create", "print"

## Example 2: Product Demo

**Filename:** `video-editor-demo.md`

```markdown
# Professional Video Editor Demo

## Getting Started

Launch the video editor application from your programs folder or dock. The interface will open with a welcome screen showing recent projects and a button to create a new project.

Click the new project button and enter a name for your video. Choose your preferred resolution and frame rate from the dropdown menus then click create to open the editing workspace.

## Importing Your Footage

Navigate to the File menu at the top of the screen and select import media. A file browser window will appear where you can locate and select your video clips from your computer.

Select multiple files by holding down the control key while clicking each file. Once you've selected all your footage, click the open button to import everything into your media bin.

## Building Your Timeline

Drag your first video clip from the media bin down to the timeline at the bottom of the screen. The clip will snap into place and you'll see the video preview in the monitor window.

Add more clips by dragging them onto the timeline next to the first clip. You can rearrange clips by clicking and dragging them to different positions in your sequence.

## Trimming and Cutting

Select a clip on the timeline by clicking on it with your mouse. Use the razor blade tool from the toolbar to split the clip at the playhead position.

Click on the unwanted section of your clip to select it. Press the delete key on your keyboard to remove that section and close the gap in your timeline.

## Adding Transitions

Open the effects panel on the left side of the screen and click on the transitions tab. Scroll through the available transitions and find the cross dissolve effect near the top.

Drag the cross dissolve transition and drop it between two clips on your timeline. The transition will automatically apply and you can adjust its duration by dragging its edges.

## Color Correction

Select a clip on your timeline and open the color panel from the right sidebar. Use the temperature slider to adjust the warmth or coolness of your footage for the desired look.

Increase the contrast slider slightly to make your image pop with deeper blacks and brighter highlights. Adjust the saturation to make colors more vibrant or more muted depending on your style.

## Adding Text Titles

Click the text tool in the toolbar and then click in the preview window where you want your text to appear. Type your title or caption and use the text properties panel to change the font.

Adjust the size of your text by dragging the corner handles or using the font size slider. Change the color by clicking on the color box and selecting from the color picker.

## Exporting Your Video

When you're happy with your edit, click the export button in the top right corner of the interface. Choose your preferred format like MP4 for online sharing or ProRes for high quality.

Select your destination folder and give your exported file a descriptive name. Click the start export button and wait while the software processes your timeline into a final video file.
```

- ~17 beats
- Durations: 5-10 seconds each
- Rich UI references: "File menu", "media bin", "timeline", "razor blade tool", "effects panel", "color picker"

## Example 3: Tech Explainer

**Filename:** `web-development-basics.md`

```markdown
# Web Development Fundamentals

## Understanding Web Pages

Every website you visit is built with three core technologies that work together. HTML creates the structure and content, CSS handles the visual styling and layout, and JavaScript adds interactivity and dynamic behavior.

## HTML Structure

HTML uses tags to define different parts of a web page like headings, paragraphs, images, and links. These tags are written with angle brackets and usually come in pairs with an opening and closing tag.

Open a text editor and create a new file called index.html on your desktop. Type the basic HTML structure starting with the DOCTYPE declaration followed by html, head, and body tags.

## Adding Content

Inside the body tags, add a heading using the h1 tag with your website's title. Below that, create a paragraph tag with some introductory text describing what your website is about.

Save your file and open it in a web browser by double-clicking the file icon. Your webpage will display in the browser showing your heading and paragraph with default black text on white background.

## Styling with CSS

Create a new file called styles.css in the same folder as your HTML file. In your HTML head section, add a link tag that connects your HTML file to your CSS stylesheet.

Open your CSS file and write a rule to change the heading color. Type h1 in curly braces and add color colon blue semicolon to make all h1 headings appear in blue text.

## Layout and Design

Add a background color to your page by targeting the body element in your CSS. Use the background-color property and choose a light gray or any color you prefer for your design.

Create spacing around your content by adding padding and margin properties to your elements. Padding adds space inside an element while margin adds space outside around other elements.

## Adding JavaScript

Create a third file called script.js and link it to your HTML using a script tag before the closing body tag. This JavaScript file will control the interactive behavior of your webpage.

Write a simple alert function that displays a welcome message when the page loads. Save all your files and refresh your browser to see the alert popup appearing on the screen.

## Next Steps

You now understand the three core web technologies and how they work together to create websites. Practice building simple pages and experimenting with different HTML tags, CSS properties, and JavaScript functions.
```

**Expected Output:**
- ~11 beats
- Durations: 5-10 seconds each
- Technical terms: "HTML", "CSS", "JavaScript", "DOCTYPE", "h1 tag", "stylesheet"
- Balanced between explanation and hands-on instructions

## Writing Tips from Examples

### Common Patterns

1. **Opening Context** - Start sections with orientation ("When you first...", "Open the...")
2. **Clear Actions** - Use imperative verbs ("Click", "Type", "Drag", "Select")
3. **Visual Landmarks** - Reference UI elements ("green button", "top left corner", "sidebar")
4. **Expected Results** - Describe what happens after actions ("You'll see...", "The window appears...")

### Word Count Balance

Each paragraph in these examples targets 15-20 words, which translates to 6-8 seconds of speech. This is the sweet spot within the 5-10 second range.

### Vocabulary Choices

- **Specific over generic**: "Visual Studio Code" not "code editor"
- **Actions over states**: "Click the button" not "The button can be clicked"
- **Visual descriptions**: "green run button" not just "run button"
- **UI locations**: "in the top right corner" not "at the top"

### Testing Your Scripts

Run any of these examples through vid-orchestrator:

```powershell
python -m vid_orchestrator docs\python-quickstart.md --output test.fcpxml --no-fetch --verbose
```

Check the console output to see:
- Number of beats generated
- Duration of each beat
- Generated search queries for stock footage and YouTube

Adjust your writing if beats are consistently too short (<5s) or too long (>10s).
